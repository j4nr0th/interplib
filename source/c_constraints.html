Constraints#

Assembly of trace constraints for differential forms on element interfaces, in both reference space and physical space, including the packed row representation of the resulting constraint matrices.

A trace constraint equates, for each test degree of freedom on a shared face, the traces of the element \(k\)-forms on both sides of the interface. In reference space the coefficient of a side is the basis inner product over the face quadrature, signed by the element orientation and with the two sides entering with opposite signs. In physical space the coefficients additionally carry the pullback of the physical \(k\)-form (through the face map’s tangential pullback, see Space Map) and the unsigned surface measure \(|\det J_{\text{face}}|\). The rows are returned in a packed representation (row offsets, component, local DoF, coefficient) so that callers can assemble their own global sparse matrices. The mathematical construction is described in Boundary Constraints.

The single-side physical-space assembly also provides a boundary load: constraint_physical_side_load() integrates the components of a \(k\)-form datum (element-frame components sampled at the canonical face points) against the trace of the element \((k-1)\)-form basis on a codimension-1 face, for every datum degree \(k = 1, \dots, n\). At \(k = n\) this is the weak Dirichlet boundary condition of the mixed formulation. Like the trace assembly it needs no surface weights or pullback, because the load is a metric-free chain integral (see Boundary Constraints).

enum constraint_status_t#

Status and error codes returned by the constraint functions.

A value of CONSTRAINT_SUCCESS means the operation completed successfully; any other value is an error and describes why the operation failed.

struct constraint_kform_spec_t#

Specification of the test k-form space on the boundary face.

The basis specifications are given for the canonical face axes, in the order the axes appear in the face.

struct constraint_element_side_t#

Specification of one side (element) of the interface.

The side has more dimensions than the test space: the first ndim - test ndim fixed axes are normal to the face, and the remaining axes span the face itself.

struct constraint_quadrature_t#

One-dimensional quadrature rule along a single canonical face axis.

struct constraint_face_quadrature_t#

Tensor-product quadrature rule over a face.

The total number of points is the product of the node counts of the individual axes and is cached in point_count.

struct constraint_trace_pullback_t#

Sampled pullback of the physical k-form onto the face.

The values are laid out so that the component for physical component p at point i of component c is stored at values[c * physical_component_count * point_count + p * point_count + i].

struct constraint_physical_batch_item_t#

One two-sided physical trace assembly item in a batch.

All items passed to the batch functions use the same test specification; their side, quadrature, metric, and pullback data may differ.

struct constraint_trace_basis_values_t#

Precomputed tensor-product basis values for trace assembly.

Values are laid out by component, then point, then local degree of freedom: values[offsets[c] * point_count + point * dofs[c] + dof]. The offsets array has component_count + 1 entries and stores cumulative DoF counts.

struct constraint_entry_t#

Single non-zero entry of an assembled constraint matrix row.

The entry couples one degree of freedom of the test space (the row) with one degree of freedom of an element side (the column).

struct constraint_rows_view_t#

Read-only view of an assembled constraint matrix in packed row form.

The rows are indexed by the degrees of freedom of the test space, in the same order as the offsets computed by constraint_kform_component_offsets. The entries of row i are entries[row_offsets[i] .. row_offsets[i + 1]).

constraint_status_t constraint_kform_component_count(const constraint_kform_spec_t *spec, size_t *out_count)#

Compute the number of k-form components of the test space.

Parameters:

  • spec – Specification of the test space. The specification is validated; on failure the outputs are left unmodified.

  • out_count – Receives the number of components, which is the binomial coefficient C(ndim, order).

Returns:

CONSTRAINT_SUCCESS on success, CONSTRAINT_INVALID_ARGUMENT if spec or out_count is null, CONSTRAINT_INVALID_DIMENSION if ndim exceeds 255, or CONSTRAINT_INVALID_ORDER if the order exceeds the dimension or a basis order is zero or the basis type is invalid.

constraint_status_t constraint_kform_component_dof_count(const constraint_kform_spec_t *spec, unsigned int component, size_t *out_count)#

Compute the number of degrees of freedom of one k-form component.

For a component with active axes (those in the wedge product) the basis order along the active axes is reduced by one, so a component of order order has prod_i (order_i + (active_i ? 0 : 1)) degrees of freedom.

Parameters:

  • spec – Specification of the test space, validated as in constraint_kform_component_count.

  • component – Index of the component, in the range [0, C(ndim, order)).

  • out_count – Receives the number of degrees of freedom.

Returns:

CONSTRAINT_SUCCESS on success, CONSTRAINT_INVALID_ARGUMENT if out_count is null or component is out of range, CONSTRAINT_INVALID_DIMENSION, CONSTRAINT_INVALID_ORDER, or CONSTRAINT_SIZE_OVERFLOW if the count does not fit in a size_t.

static constraint_status_t constraint_kform_component_offsets(const constraint_kform_spec_t *spec, size_t offset_count, size_t offsets[static const offset_count])#

Compute the cumulative offsets of the components into a flattened DoF array.

Fills offsets[0..component_count] with the start index of each component in the flattened array of all test degrees of freedom; the last entry holds the total number of degrees of freedom.

Parameters:

  • spec – Specification of the test space, validated as in constraint_kform_component_count.

  • offset_count – Number of entries available in offsets. Must be at least the number of components plus one.

  • offsets – Array of offset_count entries which receives the offsets.

Returns:

CONSTRAINT_SUCCESS on success, CONSTRAINT_INSUFFICIENT_STORAGE if offset_count is too small, otherwise the validation or overflow errors of the functions above.

Compute the number of rows and entries of a reference-space L2 trace constraint matrix.

The reference-space constraint equates, for each test degree of freedom, the trace basis coefficients on both sides of the interface. This function reports the sizes needed by constraint_reference_assemble without assembling the matrix.

Parameters:

  • sides – Array of 2 element side specifications. Each side must have more dimensions than the test space, with valid basis specifications and a valid orientation permutation.

  • out_row_count – Receives the number of rows, one per test degree of freedom.

  • out_entry_count – Receives the number of entries.

Returns:

CONSTRAINT_SUCCESS on success, otherwise the validation error of the specifications or CONSTRAINT_SIZE_OVERFLOW if a required size does not fit in a size_t. On failure the outputs are unmodified.

static constraint_status_t constraint_reference_assemble(const constraint_kform_spec_t *test_spec, const constraint_element_side_t sides[static const 2], const constraint_quadrature_t *quadrature, size_t row_offset_capacity, size_t row_offsets[static const row_offset_capacity], size_t entry_capacity, constraint_entry_t entries[static const entry_capacity], size_t *out_row_count, size_t *out_entry_count)#

Assemble a reference-space L2 trace constraint matrix into caller-owned packed rows.

The assembled matrix has one row per test degree of freedom. Each row contains entries coupling to the degrees of freedom of the two element sides, with the coefficient of side 0 being the basis inner product over the face quadrature and the coefficient of side 1 its negative.

Parameters:

  • test_spec – Specification of the test space.

  • sides – Array of 2 element side specifications, as validated by constraint_reference_required.

  • quadrature – Tensor-product quadrature rule over the canonical face, with one constraint_quadrature_t per test dimension. Each axis must have a positive node count with valid nodes and weights.

  • row_offset_capacity – Number of entries available in row_offsets.

  • row_offsets – Array which receives the packed row offsets. Must have room for row_count + 1 entries, where row_count is as reported by constraint_reference_required. row_offsets[0] is set to 0.

  • entry_capacity – Number of entries available in entries.

  • entries – Array which receives the packed entries.

  • out_row_count – Receives the number of rows written.

  • out_entry_count – Receives the number of entries written.

Returns:

CONSTRAINT_SUCCESS on success, CONSTRAINT_INSUFFICIENT_STORAGE if the provided capacities are smaller than the required sizes, otherwise the validation errors of the inputs.

The assembled matrix has one row per test degree of freedom, with entries coupling to the degrees of freedom of the given element side, weighted by the face quadrature, the unsigned face measure (surface_weights) and the sampled pullback of the physical k-form.

  • pullback – Sampled pullback of the physical k-form; only used when the form order is non-zero. Must have point_count points. May be null for order zero.

  • row_offset_capacity – Number of entries available in row_offsets.

  • row_offsets – Array which receives the packed row offsets. Must have room for row_count + 1 entries. row_offsets[0] is set to 0.

  • entry_capacity – Number of entries available in entries.

  • entries – Array which receives the packed entries, all with side set to 0.

  • out_row_count – Receives the number of rows written.

  • out_entry_count – Receives the number of entries written.

Returns:

CONSTRAINT_SUCCESS on success, CONSTRAINT_INSUFFICIENT_STORAGE if the provided capacities are smaller than the required sizes, otherwise the validation errors of the inputs.

static constraint_status_t constraint_physical_side_load(const constraint_kform_spec_t *test_spec, const constraint_element_side_t *side, const constraint_face_quadrature_t *quadrature, const double *datum_values, size_t value_count, const double *surface_weights, double values[static const value_count])#
Assemble the physical-space boundary load of one element face for a

general k-form datum.

Computes the chain integral of the components of a k-form datum (element frame, k = test_spec->order + 1) against the trace of the element (k-1)-form basis on a codimension-1 boundary face. For each face component J (element-frame axes J_e) the only contributing datum component is I = J_e U {a} with a the fixed normal axis:

values[j] = s * o * (-1)^{|{i in J_e : i < a}|} * sum_p w_p u_I(g_p) B_j(g_p) (chain integral), or, with surface_weights != NULL, the same sum with each weight multiplied by surface_weights[p] (surface-measure pairing).

Here s and a are the side and index of the fixed normal axis, o is the orientation sign of the mapped component, w_p are the reference face quadrature weights. When provided, surface_weights[p] is the absolute mapped face Jacobian determinant at the same point. u_I(g_p) is the sampled element-frame component of the datum at the canonical face points and B_j is the element basis of the traced component. At k equal to the element dimension (single datum component) the sign reduces to the outward orientation s * (-1)^a of the previous scalar-chain-integral behavior.

Parameters:

  • test_spec – Specification of the (k-1)-form test space on the face.

  • side – Element side specification with exactly one fixed normal axis.

  • quadrature – Tensor-product quadrature over the canonical face.

  • datum_values – Element-frame k-form components sampled at the canonical face quadrature points, laid out row-major as [component * quadrature->point_count + point] with combination_total_count(side->ndim, test_spec->order + 1) component rows.

  • value_count – Length of the output array: the total number of element (k-1)-form degrees of freedom.

  • surface_weights – Mapped face Jacobian at the canonical points, or NULL to assemble the metric-free chain integral.

  • values – Output array, accumulated over the mapped components.

Returns:

CONSTRAINT_SUCCESS on success, or an error status.

static constraint_status_t constraint_physical_assemble(const constraint_kform_spec_t *test_spec, const constraint_element_side_t sides[static const 2], const constraint_face_quadrature_t quadrature[static const 2], const double *const surface_weights[static const 2], const constraint_trace_pullback_t pullbacks[static const 2], size_t row_offset_capacity, size_t row_offsets[static const row_offset_capacity], size_t entry_capacity, constraint_entry_t entries[static const entry_capacity], size_t *out_row_count, size_t *out_entry_count)#

Assemble a physical-space trace constraint matrix for both sides of the interface.

Same as constraint_physical_side_assemble, but assembles the rows for both sides at once, with entries of side 0 weighted by +1 and entries of side 1 weighted by -1, so that the assembled equations express the equality of the traces of the two sides.

Parameters:

  • test_spec – Specification of the test space.

  • sides – Array of 2 element side specifications.

  • quadrature – Array of 2 face quadrature rules, one per side.

  • surface_weights – Array of 2 pointers to the unsigned face measures, one array per side.

  • pullbacks – Array of 2 sampled pullbacks of the physical k-form, one per side. Only used when the form order is non-zero.

  • row_offset_capacity – Number of entries available in row_offsets.

  • row_offsets – Array which receives the packed row offsets. Must have room for row_count + 1 entries. row_offsets[0] is set to 0.

  • entry_capacity – Number of entries available in entries.

  • entries – Array which receives the packed entries.

  • out_row_count – Receives the number of rows written.

  • out_entry_count – Receives the number of entries written.

Returns:

CONSTRAINT_SUCCESS on success, CONSTRAINT_INSUFFICIENT_STORAGE if the provided capacities are smaller than the required sizes, otherwise the validation errors of the inputs.

static constraint_status_t constraint_physical_batch_required(const constraint_kform_spec_t *test_spec, size_t item_count, const constraint_physical_batch_item_t items[static const item_count], size_t *out_row_count, size_t *out_entry_count)#

Compute storage requirements for a batch of physical trace matrices.

The same test space is used for every item. The output counts are the sums of the per-item row and entry counts, in batch order.

static constraint_status_t constraint_physical_batch_assemble(const constraint_kform_spec_t *test_spec, size_t item_count, const constraint_physical_batch_item_t items[static const item_count], size_t row_offset_capacity, size_t row_offsets[static const row_offset_capacity], size_t entry_capacity, constraint_entry_t entries[static const entry_capacity], size_t *out_row_count, size_t *out_entry_count)#

Assemble a batch of physical trace matrices into one packed matrix.

Rows from each item are concatenated in input order. Within each item the entry side field remains zero or one and retains the usual +1/-1 signs. This keeps common test-space setup and dispatch at the caller’s batch boundary while allowing geometry and orientations to vary per item.
